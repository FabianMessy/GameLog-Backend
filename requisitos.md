# Requisitos Funcionais

**RF001:** O sistema deve permitir que o usuário se cadastre na plataforma, informando:
- Nome completo
- Nome de Usuário
- E-mail
- Senha

**RF002:** O sistema deve permitir que o usuário realize login na plataforma, informando:
- E-mail
- Senha

**RF003:** O sistema deve possuir uma página de explorar jogos, contendo um carrossel com indicações, botões que levam a um filtro por categoria e um slide de jogos.

**RF004:** Ao clicar em um jogo, o sistema deve permitir visualizar seus detalhes, tais como:
- Descrição;
- Desenvolvedor(es);
- Distribuidor(es);
- Data de lançamento;
- Plataformas onde está disponível;
- Gênero(s);
- Tempo estimado/médio de gameplay;
- Idiomas disponíveis;
- Classificação indicativa;
- Nota (média das avaliações);

**RF005:** O sistema deve permitir que o usuário adicione jogos à sua biblioteca pessoal. Ao clicar em um game, caso ele ainda não esteja em sua biblioteca pessoal, deverá ter um botão que permite adicioná-lo nela. 

**RF006:** O sistema deve permitir que o usuário remova jogos da sua biblioteca pessoal. Ao clicar em um game, deverá ter um botão que permite remover o jogo da biblioteca. 

**RF007:** O sistema deve permitir visualizar a biblioteca pessoal do usuário. Nela, deve conter um filtro de visualização e todos os jogos adicionados pelo usuário.

**RF008:** O sistema deve permitir que o usuário defina o status/progresso de um jogo na sua biblioteca, podendo escolher – e mudar livremente – entre:

- Quero jogar;
- Jogando;
- Finalizado;
- Abandonado;

**RF009:** O sistema deve permitir que o usuário filtre a visualização dos jogos na sua biblioteca por:

- Avaliação (dada pelo usuário);
- Data de lançamento;
- Gênero;
- Progresso de jogo/status (quero jogar, jogando, finalizado e abandonado);
- Tempo de gameplay (do usuário);

**RF010:** O sistema deve permitir que o usuário atribua uma nota (avaliação) ao jogo na sua biblioteca. Ao clicar no jogo, ele poderá editar a nota quantas vezes quiser.

**RF011:** O sistema deve permitir que o usuário atribua uma review (análise) ao jogo na sua biblioteca. Ao clicar no jogo, ele poderá escrever uma análise deste jogo, de forma a compartilhar sua experiência com outros usuários.

**RF012:** O sistema deve permitir que o usuário atribua o tempo de gameplay do jogo na sua biblioteca, registrando quantas horas gastou naquele game.

**RF013:** O sistema deve exibir reviews de outros usuários ao final da página de detalhes de cada jogo, permitindo que o usuário leia e julgue os jogos pelos olhos de outros usuários.

**RF014:** O sistema deve permitir navegação entre as páginas: catálogo de jogos, minha biblioteca e perfil do usuário.

**RF015:** O sistema deve exibir o perfil do usuário.

**RF016:** O sistema deve exibir que, no perfil do usuário, este possa editar suas informações e realizar logout.
